## 尚待账号验收与边界

- QQ 扫码和真实消息往返仍由用户亲自执行。首页只有用户确认收到回复才会记录实测完成，不以配置成功冒充消息成功。
- QQ 空间的真实查看、发布、点赞、评论和删除没有在用户账号上执行。本轮只验证安装、接口准备与启停；账号业务兼容性待用户实测。
- 空间分项开关控制小屋操作和绑定角色的 AI 工具，总开关停用整个插件。原生插件命令有独立的 AstrBot 权限，不能把小屋开关说成全局隔离。上游 AI 工具组合了查看、点赞、评论与图文发布，允许 AI 时需同时开启这些项目。
- 现成插件的稿件生成与审核等高级操作保留在 AstrBot 原生插件中，小屋没有重做完整管理面板。
- B 站尚未实现平台适配，界面标明预留，不提供假可用开关。
- 当前受限自动化执行环境需要测试参数 --no-sandbox；交付程序未默认加入该参数。0.1 已被用户在普通桌面打开，0.3 仍需用户普通桌面试用。
- 设备加密凭据需要同一 Windows 用户与原应用数据配置。目录迁移、其他机器、自动更新和回退尚未验收。
- 交付文件夹版；单文件便携 EXE 的临时解压清理与后台组合未验收。

## 可复现脚本

- npm run check / npm test：语法和 31 项回归。
- node scripts/verify-workspace.cjs：模型、人设、分段、插件、会话与原生入口；--packaged 检查打包版本。
- node scripts/smoke-ui.cjs：教程、自定义图片与界面。
- node scripts/verify-lifecycle.cjs：独立后台、原生模型与角色即时应用、概率回复、完整停止。
- node scripts/verify-qzone.cjs：固定空间插件安装与开关，不执行公开操作。
- node scripts/verify-exit.cjs：窗口关闭的取消与彻底退出。
- npm run pack 后执行 node scripts/verify-lifecycle.cjs --packaged：包括程序目录改名解除占用验证。
- python scripts/bundle.py：打包、检查压缩包和生成 SHA-256。

结果保存在 .test-artifacts 的 lifecycle-result.json、packaged-lifecycle-result.json、qzone-result.json 与 exit-result.json。界面截图为 home.png、settings.png、features.png 和 tools.png。
