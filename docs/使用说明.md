# QQ AI 小屋 0.2 · Windows 内测版

完整解压后双击「QQ AI 小屋.exe」。新版沿用旧版的本机应用配置和安装位置；不要删除 D:\QQ-AI 等安装目录来更新小屋。

1. 新用户在「我的小屋」选择专用安装目录，安装后点击「启动角色」。老用户直接沿用已有安装。
2. 点击「复制 Token 并打开登录页」。在浏览器的 Token 框按 Ctrl + V，点击登录，再用手机 QQ 扫码。
3. 在「角色与模型」填写自己的角色名字、设定和 DeepSeek 密钥。先测试密钥，再点击「保存并应用角色与设置」。保存会即时应用，不需要重启 QQ。
4. 用另一个 QQ 私聊角色发送「你好」。确认收到回复后，再在首页点击「我已在 QQ 收到回复」。配置完成不会自动冒充消息实测通过。

右侧教程会跟随当前步骤，也可手选 Token、模型、群聊、空间或退出等主题，并提供可以直接点击的入口。

## 自己创造角色与布置小屋

新装不预设名字、性别、身份或关系。模板只是可编辑的提示词起点；旧版已保存的人设保留。

在「布置小屋」上传头像、立绘或背景图，可调整配色、卡片清晰度和背景模糊。图片保存在本机应用目录，不发送给模型，也不自动修改 QQ 头像。支持 PNG、JPG、WebP，单张不超过 12 MB。

## 互动与空间开关

默认私聊直聊、群聊 @ 回复。可选择触发词，或启用 AstrBot 自带概率主动接话并限定群号。主动接话前先在群里进行一次正常对话，建立会话。

QQ 空间为可选插件，安装后默认停用。选择权限并应用后可使用手动操作；自动发布、自动评论需要分别开启并填写时间。分项开关控制小屋入口与角色的 AI 工具，原生插件命令仍由 AstrBot 管理。空间真实发布和互动尚待账号实测。

## 关闭、退出和删除

- 「停止机器人」结束 AstrBot、NapCat 和托管进程，面板保留。
- 「停止机器人并彻底退出」结束所有这些进程并关闭面板。结束使用或准备删除安装目录时选择此项。
- 「仅关闭面板，后台继续」保持机器人运行。新后台使用安装目录内的运行环境，不使用小屋解压目录中的 EXE。
- 关闭右上角 × 会询问退出方式，默认选择停止并退出。

删除程序的解压目录与删除角色安装数据是两件事。退出操作不会删除聊天、角色或插件数据。删除机器人安装目录前要彻底退出。

设备加密凭据需要原 Windows 用户和原应用数据配置，请一并保留。更新与自动回退尚未开放。测试范围和限制见「验收记录.md」。
